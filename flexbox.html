O que é Flexbox?

Flexbox é um modelo de layout do CSS que facilita a organização dos elementos em uma linha ou coluna. Para usá-lo, coloque display: flex; no elemento que contém os itens.

1. display: flex

Por padrão, os itens ficam lado a lado.

Item 1
Item 2
Item 3
.container {
  display: flex;
}

2. flex-direction

Define a direção dos itens: em linha (row) ou em coluna (column).

Item 1
Item 2
Item 3
.container {
  display: flex;
  flex-direction: column;
}

3. justify-content

Alinha os itens no eixo principal. Neste exemplo, eles ficam distribuídos com espaço entre eles.

Item 1
Item 2
Item 3
.container {
  display: flex;
  justify-content: space-between;
}

4. align-items

Alinha os itens no eixo transversal. Aqui, os itens estão centralizados verticalmente.

Item 1
Item 2
Item 3
.container {
  display: flex;
  align-items: center;
}

Resumo

  • display: flex; ativa o Flexbox.
  • flex-direction define a direção dos itens.
  • justify-content organiza os itens no eixo principal.
  • align-items alinha os itens no eixo transversal.
  • gap define o espaço entre os itens.
